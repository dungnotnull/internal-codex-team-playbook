## Method

1. **Snapshot for audit:** all questions extracted verbatim to `research/quiz-audit-input.json`.
2. **Independent factual audits:** three independent reviewer passes (Q1-14, Q15-27, Q28-40), each checking
   every factual claim in correct options, every distractor (must be genuinely wrong), every note claim
   (paths / defaults / numbers / behaviors), ref plausibility, and vi/ja mirror integrity. All checks
   were performed against the official docs corpus in `research/openai-docs/` (23 files, fetched from
   `learn.chatgpt.com` on 2026-11-12), plus direct fetches of individual doc pages where needed.
3. **Link freshness:** all **30 unique reference URLs** re-verified by direct HTTP GET on 2026-11-12
   (`research/ref-url-status-2026-11-12.txt`): 27x HTTP 200; 3x help.openai.com return 403 to scripted
   clients by design and were verified in a real signed-in browser pane during research (same day).
4. **Images:** `quiz/img/*.webp` (official MCP poster, official IDE illustration) and
   `quiz/img/openai-developers.svg` (official docs-site wordmark, fetched 2026-11-12) all verified
   loading in a real browser with correct natural sizes.
5. **Engine integrity:** `node --check` on all JS; vi/ja pair integrity (n=40, identical multi/correct/
   option ordering/ref URLs/img ids); em-dash/en-dash sweep (0); browser E2E (40 cards, 10 multi,
   full-correct grading = 10.00/10, 0 console errors).
